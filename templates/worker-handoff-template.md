# 기획팀장–직원 업무 배정·반환 계약

모든 직원은 배정된 업무와 출력 위치만 사용한다. 프로젝트 루트의 팀장 지침은 공통 운영 계약이며, 호출된 직원이 자신을 팀장으로 재해석하거나 다른 직원을 호출하라는 뜻이 아니다.

## 팀장 → 직원

- 작업 ID:
- 담당 역할·반드시 읽을 전문 지침:
- 프로젝트 루트 절대경로:
- 연구명·연구 폴더 절대경로:
- 작업 목적과 이번 요청 범위:
- 사용자 제공 사실:
- 가정·제안·확인 필요 사항:
- 입력 파일 절대경로·문서 상태·필요한 해시:
- 읽기 전용 파일과 쓰기 허용 파일·폴더:
- 승인 근거·승인된 조건·포함되지 않은 작업:
- 이전 검토·재시도 횟수 및 이어받을 결과:
- 완료 조건과 반환 시점:

직원에게 이 파일과 전문 지침을 읽도록 지시한다. 확인 질문·승인 요청은 직접 사용자에게 보내지 말고 아래 반환 형식에 포함하게 한다.

## 직원 → 팀장

- 작업 ID·담당 역할:
- 상태: 대기 / 진행 중 / 승인 대기 / 완료 / 부분 완료 / 실패
- 실제 수행한 작업:
- 사용한 입력 경로·상태·해시:
- 생성·갱신한 산출물의 절대경로:
- 처리 수: 대상 / 성공 / 주의 / 실패 / 제외·미처리
- 검토·재시도 횟수(없으면 0):
- 원본 보존 확인 근거 또는 미검증 이유:
- 미해결 문제와 문헌별 실패·제외 이유:
- 사용자에게 확인할 질문 또는 대안: 최대 3개
- 다음 직원에게 전달 가능한 파일·문헌 ID·상태:

파일을 쓰지 못했거나 실제 작업을 하지 않았으면 해당 사실을 적는다. 직원은 `00_진행상황.md`를 갱신하지 않으며, 반환 상태는 팀장의 확인 후 진행기록에 반영된다.
